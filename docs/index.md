# Architect Study Hub

Base de conocimiento de **teoría y práctica** de todo lo que un arquitecto / ingeniero de software de primer
nivel debe tener siempre en la cabeza: fundamentos, diseño, arquitectura, sistemas distribuidos, plataforma,
inteligencia artificial y cloud. Cada tema combina explicación, **ejemplos de código**, diagramas, **preguntas de repaso** y **ejercicios**.

## Cómo se lee cada página

| Elemento | Significado |
|---|---|
| <span class="nivel basico">Básico</span> <span class="nivel medio">Medio</span> <span class="nivel avanzado">Avanzado</span> | Profundidad del tema |
| Caja **tip** | Idea clave que conviene saber explicar en una frase |
| Caja **question** plegable | Pregunta de repaso: intenta responder antes de abrirla |
| Caja **exercise** | Ejercicio graduado (básico, medio, avanzado); su **solución** está plegada debajo: intenta resolverlo antes de abrirla |
| Caja **warning** | Trade-off, riesgo o dato que caduca |
| Burbuja de chat (abajo a la derecha) | Asistente de IA que responde dudas con el contenido de la página como contexto; si seleccionas un fragmento antes de abrirlo, puedes preguntar por él. Funciona con el servidor local encendido (ver README) |

Usa el buscador (tecla `/` o la lupa) para saltar directamente a cualquier concepto.
