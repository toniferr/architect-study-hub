# Biblioteca

Resúmenes **en mis propias palabras** con ejemplos de código, pensados para repasar rápido. No sustituyen
a los libros: son la chuleta para después de leerlos.

| Libro | Autor | Qué aporta | Página |
|---|---|---|---|
| Clean Code (*Código Limpio*) | Robert C. Martin | Criterio de calidad a nivel de código | [Resumen](clean-code.md) |
| Clean Architecture (*Arquitectura Limpia*) | Robert C. Martin | Límites, dependencias y testabilidad de servicios | [Resumen](clean-architecture.md) |
| System Design Interview (vol. 1 y 2) | Alex Xu | Método para diseñar sistemas a escala | [Resumen](system-design-interview.md) |
| Cracking the Coding Interview | Gayle L. McDowell | Resolución de problemas y algoritmia | [Resumen](cracking-the-coding-interview.md) |

Cada resumen enlaza con las páginas temáticas donde ese conocimiento se desarrolla en más detalle.
